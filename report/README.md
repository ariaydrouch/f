# BTP Progress Report

LaTeX source for the progress report, following the supplied
`Sample_BTP_Latex.tex` template (same document class, preamble, title-page
layout and section structure).

## Contents

```
BTP_Progress_Report.tex     the report
figures/                    8 vector figures, generated from the notebooks
```

## Before compiling

Copy `Logo-IITD.jpg` from the template package into this folder. It is the only
file the report needs that is not here.

## Before submitting

Search the `.tex` for `FILLME`. There are four places:

1. course code — currently `PYD411`, change if it should be PYD412 or PYD414;
2. academic year and semester — currently `2025 - 2026, Semester - I`;
3. student name and entry number (a commented-out second line is there if the
   project has two students);
4. adviser's name, in the title block **and** in the Acknowledgements.

## Compiling

```bash
pdflatex BTP_Progress_Report.tex
pdflatex BTP_Progress_Report.tex     # twice, so cross-references resolve
```

Verified with pdfTeX 3.141592653 (TeX Live 2023): 16 pages, no errors, no
undefined references or citations. Only `amsmath`, `amsfonts`, `amssymb`,
`epsfig`, `hyperref`, `subfig`, `soul` and `xcolor` are used, all of which the
template already loads — no packages were added.
